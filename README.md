* Zingen

Óla. Projeto desenvolvido como o 4º trabalho da disciplina de Programação para Web e Dispositivos Móveis.

O **Zingen** é uma página web inspirada em um aplicativo de música e karaokê. O objetivo do projeto foi reproduzir uma interface proposta em aula, utilizando **HTML e CSS**, buscando manter o resultado final o mais semelhante possível ao modelo apresentado.

* Sobre o projeto

O projeto foi desenvolvido sob orientação do professor Cristian Thaiur.Entre os trabalhos realizados até o momento na disciplina, o Zingen foi um dos projetos que considerei mais complexo, principalmente por exigir maior atenção na organização da página, estilização dos elementos, fontes, espaçamentos e alinhamentos.

Durante o desenvolvimento, algumas das principais dificuldades estiveram relacionadas ao posicionamento dos elementos na página, alinhamento de algumas partes do layout e configuração das fontes.

Apesar dos desafios, o resultado final foi bastante satisfatório para mim e ficou muito semelhante à proposta apresentada.

Este projeto também representou uma evolução importante em relação aos trabalhos anteriores, permitindo colocar em prática e aprimorar meus conhecimentos em desenvolvimento web.

* Funcionalidades da página

A página apresenta diferentes seções do aplicativo Zingen, incluindo:

- Apresentação do aplicativo
- Funcionalidades do Zingen
- Biblioteca de músicas para karaokê
- Experiência gamificada
- Gravação de performances
- Compartilhamento com a comunidade
- Letras de músicas em tempo real
- Planos e preços
- Área para download do aplicativo
- Rodapé com informações e redes sociais

 * Aprendizados

Durante o desenvolvimento deste projeto pude evoluir principalmente em:

- Estruturação de páginas utilizando HTML
- Organização e separação dos arquivos CSS
- Utilização de classes
- Flexbox
- CSS Grid
- Alinhamento e posicionamento de elementos
- Utilização de imagens e ícones
- Responsividade
- Organização visual da página
- Uso de fontes em projetos web

Também consegui compreender melhor como pequenos ajustes de espaçamento, tamanho, alinhamento e posicionamento podem fazer uma grande diferença no resultado visual de uma página.
